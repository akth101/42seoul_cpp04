1. 과제를 통해 알게 된 것

1-1) 깊은 복사와 얕은 복사  
얕은 복사는 주소만 복사하기 때문에 여러 변수가 똑같은 데이터를 가리킬 수 있지만, 깊은 복사는 아예 다른 메모리 공간을 할당한 후 내용을 새로 복사한다는 차이점이 있습니다.  

1-2) 상속 시 소멸자에 virtual 키워드를 붙이는 것의 중요성  
포인터의 정적 타입이 아닌 실제 객체의 타입에 맞는 소멸자를 호출할 수 있기 때문입니다.
